How it works

2. Meta forwards itWhatsApp (Meta Cloud API) sends the message to our server's webhook.
3. Security checkThe server checks that the request really came from Meta.
4. AI thinksThe message and recent chat history go to the AI model ({{MODEL}}).
5. You get a replyThe server sends the AI answer back to your WhatsApp.
